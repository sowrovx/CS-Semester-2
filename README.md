Project 1 — Chef Koko's Sentence Kitchen

Course: CCC1243 Artificial Intelligence | Group Project

An adaptive AI-driven educational game built with Python + Pygame that teaches kindergarten children aged 4–6 to construct basic English sentences through drag-and-drop word tiles in a cartoon kitchen environment.

Project 2 — AIU Parcel Tracker System

Course: Object-Oriented Programming | Group Project

A Java-based parcel tracking system developed for Albukhary International University, allowing students and staff to submit, track, and manage parcel deliveries on campus.
